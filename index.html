Node 01
核心任务

科学上网的本质

学到核心

科学上网就是为了伪装成外国人访问网络。机场就是为了使得飞机能够飞行（提供翻墙服务等平台），节点就是机场具体的连接线路。

深度复盘

1、网站的访问过程

打开 bilibili.com（域名），电脑开始进行 DNS 解析——将域名翻译为 IP 的系统（可能是 120.xxx.xxx.xxx），电脑访问到了，才出现了我们看到的页面。一切的网站实际部署在服务器。

2、淘宝为何多人同时访问不卡

  • 淘宝域名通过 DNS 轮询解析，一个域名可对应海量不同服务器 IP 地址
  • 不同地区用户自动解析到就近节点 IP，接入本地服务器集群
  • 再经负载均衡把流量分到无数后端业务服务器
  • 大量用户被分散到不同 IP 对应服务器，单台服务器压力极小

3、网络规格常见形式

服务器地址：8.8.8.8 或 node.my-node.com
端口：443 / 8443
协议：VLESS / VMess / Trojan / Shadowsocks
认证信息：UUID / 密码
传输方式：TCP / WebSocket / gRPC
TLS：是否开启加密证书

提示词工程

学到核心

写好提示词的最好方法就是站在机器的角度与机器对话，要对问题建立自己的框架，拆分成大类，写出粗略的提示词，然后用 AI 来进行润色提示词，获得较好的效果。这里提出一个概念——BRTRE 原则，比较通用。总之，多对话，多总结，你才能获得感受。

深度复盘

1、AI 本质

看透 AI 的本质是什么，不要魔化，要合理利用 AI，多和 AI 沟通对话。网上短视频很多，更多的是吸引你的注意力。AI 时代，千万不要引起焦虑，因为很多东西你都不需要，它只是一个提效的工具。

2、Markdown 与 JSON 格式的学习

Markdown

面向人的轻量化排版格式，用来规整文字、做整洁笔记。学会 Markdown 能彻底解决内容复制排版乱象，高效整理学习资料，统一文档样式。

JSON

面向程序与 AI 的标准化数据格式，用来规整、传输、存储各类数据。是后续 AI 精准操控、批量处理数据、对接各类工具接口、实现自动化操作的核心基础。

JSON 格式示例：

{
  "角色": "小红书爆款写手",
  "Skills": ["心理学", "痛点挖掘", "emoji排版"],
  "Task": "写一篇关于AI焦虑的笔记",
  "Constraints": {
    "Tone": "毒舌但真诚"
  }
}

图片 / 视频生成

学到核心

依旧是框架思维。明确生成图片的要素（核心主体 + 细节特征 + 环境背景 + 光影/色调 + 渲染/相机参数）和视频的要素（背景，主体，运镜，画风，客体，环境），写出粗略的提示词，然后利用 AI 对提示词进行优化，提高生成质量。

深度复盘：ComfyUI

ComfyUI 是一个开源、节点式的 AI 工作流引擎，最常用于 Stable Diffusion 等扩散模型的可视化创作，也支持视频、音频和 3D 生成。你可以把它想象成 AI 创作的"可视化编程画布"——所有生成步骤都变成一个个"乐高积木块"（节点），拖拽连接就能拼出任意复杂的创作流程。

节点式操作

把 AI 生成拆成独立功能节点，像画流程图一样拼出工作流，全程可视化、可修改。

极致可控

支持分支、循环、多模型混用，能精确调整每一步参数，生成效果完全由你掌控。

高效复用

工作流可保存为文件一键分享/导入；生成的图片自带"流程元数据"，拖回即可还原完整创作过程。

总结：ComfyUI 不是简单的"AI 绘图工具"，而是 AI 创作的"操作系统"——把 AI 生成的"控制权"彻底交还给用户。

核心任务 B

HTTP 请求

学到核心

生图软件常规运行逻辑：客户端文字发送 → 前端 → 后端 → HTTP请求 → 大模型 → 生成 → HTTP请求 → 前端。这里面运行了两次 HTTP 请求。利用 AI 把生图时后端实际产生的代码直接放到终端里面，同样可以得到想要的图片。

深度复盘：API中转站的核心逻辑

一、API 本质：AI 的"后厨窗口"，跳过官方网页界面，直接调用模型能力，按用量计费、更便宜灵活。

二、四大角色（合规性从高到低）：官方企业直签 → 云厂商通道 → 共享账号池（灰色暴利、水最深） → 聚合平台/批发商

三、中转技术核心 8 步流程：用户请求 → 鉴权（验 Key/余额）→ 限流 → 入队 → 调度（选健康/充裕/就近账号）→ 上游调用 → 回包 → 重试/熔断

四、暴利核心：前端定价套路（超低价引流、虚标额度、模型倍率定价）+ 后端技术压成本（调度算法、超卖、模型偷换、损耗控制）

核心结论

  • 低价 API 的"便宜"，本质是违规成本、损耗成本、信息差的转移
  • 普通用户避坑三问：账号渠道是否清晰？价格是否低于合理成本？服务是否稳定可追溯？
  • AI 时代，独立思考判断力，比廉价算力更重要

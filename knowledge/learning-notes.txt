=== 教学卡片1：科学上网的本质 ===
核心任务：科学上网的本质、机场与节点概念、VPS 搭建
学到核心：科学上网就是为了伪装成外国人访问网络。机场就是提供翻墙服务的平台，节点就是机场具体的连接线路。通过 VPS（虚拟专用服务器）搭建自己的节点，实现安全、稳定的科学上网。常用协议包括 VLESS、VMess、Trojan、Shadowsocks，传输方式有 TCP、WebSocket、gRPC 等。
深度复盘：打开 bilibili.com（域名），电脑开始进行 DNS 解析——将域名翻译为 IP 地址的系统（例如翻译为 120.xxx.xxx.xxx），电脑访问到对应服务器，才出现我们看到的页面。一切网站实际部署在服务器上。淘宝域名通过 DNS 轮询解析，一个域名可对应海量不同服务器 IP 地址。不同地区用户自动解析到就近节点 IP，接入本地服务器集群，再经负载均衡把流量分到无数后端业务服务器，单台服务器压力极小。大量用户被分散到不同 IP 对应服务器。网络规格常见形式：服务器地址 8.8.8.8 或 node.my-node.com 域名、端口 443/8443、协议 VLESS/VMess/Trojan/Shadowsocks、认证信息 UUID/密码、传输方式 TCP/WebSocket/gRPC、TLS 是否开启加密证书。翻墙的核心就是让你的网络流量看起来像正常的 HTTPS 流量，绕过 GFW 的检测。
成果展示：成功配置搬瓦工 Bandwagon VPS，电脑手机均实现科学上网，能自由访问 Google、YouTube、Twitter 等境外网站。

=== 教学卡片2：提示词工程 ===
核心任务：提示词工程 Prompt Engineering、BRTRE 原则、Markdown 与 JSON 格式
学到核心：写好提示词的最好方法就是站在机器的角度与机器对话。要对问题建立自己的框架，拆分成大类，写出粗略的提示词，然后用 AI 来进行润色提示词，获得较好的效果。BRTRE 原则（Background 背景、Role 角色、Task 任务、Requirement 要求、Example 示例）比较通用。核心是结构化思维——把模糊的需求转化为精确的指令。多对话，多总结，才能获得对 AI 行为的直觉感受。
深度复盘：看透 AI 的本质是什么——它是基于大规模语言模型的文本预测工具，不是有意识的存在。不要魔化 AI，要合理利用它作为提效工具。网上短视频很多，更多是吸引注意力制造焦虑。AI 时代千万不要引起焦虑，因为很多东西你都不需要，AI 只是一个提效的工具。Markdown 是面向人的轻量化排版格式，用来规整文字、做整洁笔记，学会 Markdown 能彻底解决内容复制排版乱象。JSON 是面向程序与 AI 的标准化数据格式，用来规整、传输、存储各类数据，是后续 AI 精准操控、批量处理数据、对接各类工具接口、实现自动化操作的核心基础。
成果展示：AI 图片生成作品（布偶猫）—— 一只毛茸茸的、橘色重点色的布偶幼猫在户外草坪上伸懒腰，夕阳余晖洒在毛发上，营造金色柔和光影。

=== 教学卡片3：图片视频生成 + HTTP请求 ===
核心任务A：图片/视频生成、ComfyUI 工作流、AI 绘图要素框架
学到核心：依旧是框架思维。明确生成图片的要素（核心主体 + 细节特征 + 环境背景 + 光影/色调 + 渲染/相机参数）和视频的要素（背景、主体、运镜、画风、客体、环境），写出粗略的提示词，然后利用 AI 对提示词进行优化，提高生成质量。AI 绘图不是玄学，而是可控的参数组合。
深度复盘：ComfyUI 是一个开源、节点式的 AI 工作流引擎，最常用于 Stable Diffusion 等扩散模型的可视化创作，也支持视频、音频和 3D 生成。可以把它想象成 AI 创作的"可视化编程画布"——所有生成步骤都变成一个个"乐高积木块"（节点），拖拽连接就能拼出任意复杂的创作流程。三大特点：节点式操作（像画流程图一样拼工作流）、极致可控（支持分支、循环、多模型混用）、高效复用（工作流可保存分享，生成图片自带流程元数据）。ComfyUI 不是简单的"AI 绘图工具"，而是 AI 创作的"操作系统"——把控制权彻底交还给用户。Stable Diffusion 是目前最主流的开源图像生成模型，基于扩散模型原理，通过逐步去噪生成图像。
核心任务B：HTTP 请求、API 调用原理、API 中转站商业模式
学到核心：生图软件常规运行逻辑：客户端文字发送 → 前端 → 后端 → HTTP请求 → 大模型 → 生成 → HTTP请求 → 前端。这里面运行了两次 HTTP 请求。利用 AI 把生图时后端实际产生的代码直接放到终端里面调用，同样可以得到想要的图片，绕过了前端界面。HTTP 请求是互联网通信的基础协议，GET 获取数据，POST 提交数据。
深度复盘：API 本质是 AI 的"后厨窗口"——跳过官方网页界面，直接调用模型能力，按用量计费、更便宜灵活。四大角色（合规性从高到低）：官方企业直签 → 云厂商通道（阿里云、AWS 等）→ 共享账号池（灰色暴利、水最深）→ 聚合平台/批发商（OneAPI、New API 等）。中转技术核心 8 步流程：用户请求 → 鉴权（验 Key/余额）→ 限流（防滥用）→ 入队（消息队列）→ 调度（选健康/充裕/就近账号）→ 上游调用（转发给真实 API）→ 回包（返回结果）→ 重试/熔断（故障处理）。暴利核心：前端定价套路（超低价引流、虚标额度、模型倍率定价）+ 后端技术压成本（调度算法优化、超卖、模型偷换、损耗控制）。核心结论：低价 API 的"便宜"，本质是违规成本、损耗成本、信息差的转移。普通用户避坑三问：账号渠道是否清晰？价格是否低于合理成本？服务是否稳定可追溯？AI 时代，独立思考判断力比廉价算力更重要。OneAPI 是目前最流行的 API 聚合管理平台，支持多模型统一管理和分发。
